What leaves this device

When you analyze tabs, titles, up to 2,048 URL characters, pinned state, and current group names go to ChatGPT. A temporary number matches each result to its tab; it is not the Chrome tab ID. Page contents are not read, and the browser password store is not accessed. A URL can itself contain sensitive data, such as an access token in its query string, and that text may be sent.
