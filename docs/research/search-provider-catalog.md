# Search provider catalog and first-release shortlist

**Research snapshot:** 6 November 2026 · **Status:** decision support; no product integrations are proposed by this document.

## Scope and reading guide

This is a broad catalog of public web destinations that a keyboard command bar could hand a query to. It covers global and regional web search, AI answer/chat, video, social and communities, shopping, maps/local search, developer/reference search, knowledge/media, and the **Chrome Web Store itself**. It is intentionally not an inventory of every niche, self-hosted, short-lived, adult, or country-specific site. Search-provider markets and web routes change; verify a candidate's URL and availability again when Pedro chooses it.

**URL notation:** `%s` is a single URL-encoded query. In the tables, `Current` or an unqualified `Candidate` means **Yes**: the row has a public query URL pattern that can be opened directly. `Candidate · limited` means the site may require sign-in, a region, an instance, or client-side state, or a durable query route/prefill could not be confirmed. A row that says there is no stable query URL is **No** for query handoff (though a site-open shortcut may still be possible). “Observed URL” is evidence of a handoff, not a promise by the provider to preserve that route forever. A query handoff opens the provider's site; it is not a private API or in-extension results.

**Completion notation:** for every listed name token `token{2..n}`, include each prefix of that token from two characters through the complete token. For example `youtube{2..7}` means `yo, you, yout, youtu, youtub, youtube`; this makes completions deterministic without hiding a hand-picked subset. Each component of a multiword name is listed, so word-level prefixes are generated too. Practical abbreviations, old names, and useful aliases follow `+`. One-character triggers are excluded from the generated set unless called out explicitly; they have high collision risk. Case and spaces are ignored by the proposed completion matching.

**Icons and shortcuts:** each linked provider homepage is also the source of its own declared favicon (the site's `rel=icon` asset, not a third-party logo API). Use only the favicon/brand asset actually served there and check that provider's brand or terms guidance before bundling it; a public favicon is not a blanket redistribution license. Fallback: Keybar's generic search glyph or a text monogram. Native keyboard shortcuts are recorded separately from Keybar triggers. “Not located in official desktop docs” means no stable, provider-wide desktop shortcut was found during this review; it does not rule out browser, app, accessibility, or OS shortcuts. YouTube's `/` shortcut focuses its search field when the page can receive keyboard input.

**Competitor evidence:** the comparison below distinguishes a named built-in preset from a configurable arbitrary URL. It does not infer that a competitor ships every provider as a preset. The explicit competitor sources are the [TypeGo Chrome Web Store listing](https://chromewebstore.google.com/detail/typego-address-bar-search/ifgfnphneemmhccaknmidjnhemkhnoah), [TapTap - Quick Search listing](https://chromewebstore.google.com/detail/taptap-quick-search/bdodpnpniemjlacmdjcaeeagndkmliac), [Context Menu Search listing](https://chromewebstore.google.com/detail/context-menu-search/jiemcgfaaankhcphdbfbilkldedojieb), [Selection Search listing](https://chromewebstore.google.com/detail/selection-search/gipnlpdeieaidmmeaichnddnmjmcakoe), and [Vimium C's custom search documentation](https://github.com/gdh1995/vimium-c/wiki). TypeGo names Google, ChatGPT, YouTube, GitHub, Translate, and Wikipedia as built-ins and advertises adding arbitrary URL patterns. TapTap names Google, Naver, ChatGPT, Claude, and Perplexity and advertises custom engines. Context Menu Search advertises 60+ presets and custom engines but does not expose the preset names in the listing. Selection Search exposes a customizable engine list. Vimium C documents user-defined URL templates and aliases. These are direct feature claims from their publishers/store listings; preset claims are marked only where the provider name is explicit.

## Alias collisions and trigger recommendations

Generated prefixes are suggestions, not a final reserved namespace. Resolve duplicate aliases at selection time; do not silently assign a short prefix to whichever provider sorts first. These high-salience collisions already appear in this catalog:

| Alias/prefix family | Colliding providers | Safer approach |
| --- | --- | --- |
| `g`, `go`, `goo`, `google` | Google web, Google Maps, Google Shopping, Google Scholar, Google Books, Google News, Go Packages (`go`) | Reserve `g` for current Google web; use `gm` for Maps, `gshop` for Shopping, `gs` for Scholar, `gb` for Books, `gn` for News, and `gopkg` for Go Packages. Keep `gemini` as Gemini's unique trigger; never auto-bind a shared Google prefix. |
| `yo`, `you` | YouTube, You.com | Keep `yt` for YouTube; prefer `youcom` for You.com. |
| `ya` | Yahoo, Yandex | Keep `yh`/`yahoo` for Yahoo; prefer `yan`/`yandex` for Yandex. |
| `ma`, `maps` | Google Maps, Apple Maps, Bing Maps, Naver Map; also Map-related word prefixes | Prefer `gm`, `amaps`, `bm`, `nmap`; treat `ma` and `maps` as completion results, not committed triggers. |
| `chat` | ChatGPT, Mistral Le Chat, HuggingChat | Keep existing `chat` for ChatGPT; use `lechat` and `hfchat` for others. |
| `ai` | Current ChatGPT, Meta AI | Keep Keybar's existing `ai` trigger for ChatGPT; use `metaai` for Meta AI. |

## Research limits and next verification

- This is a curated longlist of **107** destinations (7 current Keybar providers and 100 candidates) across the categories above, not a claim of exhaustive worldwide coverage. It deliberately favors active, direct-to-user destinations with plausible use from a keyboard-first Chrome command bar.
- A concurrent live URL smoke check attempted 87 query templates with `keybar`; most returned a page or redirect, while a smaller set returned rate limits, login/captcha pages, HTTP errors, or connection blocks. Chrome Web Store, Google Maps, Naver, TikTok, Twitch, Cốc Cốc, Reddit, ChatGPT, Threads, Startpage, and Vimeo returned HTTP 200 in at least one check. Facebook's `/search/top/` and the old Komo `/search` route returned 404. Google Shopping's older `tbm=shop` URL redirected to general results, so the direct Shopping host is listed instead. These checks establish URL reachability only, not rendered, logged-in, or successful search behavior.
- Search URLs without a provider-published setup document are observed public patterns and should be checked by opening a query containing reserved characters, Unicode, and spaces. Several services change routes or require client state.
- Provider homepages are the primary source for their name and favicon origin. The source link is not proof of permission to redistribute its mark. Do not bundle assets until their brand/license terms are checked.
- Competitor comparison is an affordance snapshot, not a comprehensive extension-store census. It directly verifies named built-ins in TypeGo and TapTap, and verifies custom-engine support in several command/context-search extensions. It does not assert unnamed presets. TypeGo's small listing sample and TapTap's very small review count are not popularity evidence.
- Queries leave Keybar and are sent to the destination when the user chooses the provider result. A provider's privacy policy and regional handling apply; Keybar should not imply that a third-party handoff is local or anonymous.
- Before implementation, verify selected URL templates and favicon paths in Chrome, check Chrome Web Store listing/region restrictions, resolve alias conflicts, and capture the official source/terms for any packaged brand assets.
