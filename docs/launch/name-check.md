# Chrome extension name check

**Checked:** 2 November 2026

**Product:** Chrome extension in [`pedrotmr/command-menu-chrome-extension`](https://github.com/pedrotmr/command-menu-chrome-extension)

## Recommendation

Switch the product name from **Command Menu** to **Duvira**, subject to a formal trademark review before filing or launch. Keep **Command Menu** as a description of the interface where it helps users understand the feature.

The current label exactly matches a built-in [Chrome DevTools Command Menu](https://developer.chrome.com/docs/devtools/command-menu). That creates search confusion before the extension has a listing. Google’s [Chrome Web Store branding rules](https://developer.chrome.com/docs/webstore/branding) also caution against Google trademarks and confusingly similar branding. Duvira is the strongest of these three screens: it fits the product’s quiet, precise character, avoids naming the generic interface, and has an unregistered `.app` domain in this RDAP check. Its `.com` is already used by an unrelated nutrition business, and a similar-sounding U.S. mark exists in a different class, so this is a recommendation for further clearance, not a declaration that the name is legally clear.

## Product and current name

[`PRODUCT.md`](../../PRODUCT.md) describes a keyboard-first tool for local search, browser commands, external search handoffs, and tab management. Its character is “quiet, precise, capable,” and it explicitly says naming is open. The README calls **Command Menu** a working name.

The current name is present in [`src/manifest.json`](../../src/manifest.json) as the extension name, description, action title, and command description. The README also uses it in the heading and shortcut guidance. The separate `Command Bar` and `Tab Switcher` surfaces should remain feature names unless product copy gives a reason to change them.

## Trademark screen

The screening focused on Nice classes **9** (downloadable software) and **42** (software and technology services). The exact candidate terms were searched in the [INPI trademark database](https://servicos.busca.inpi.gov.br/marcas/) and the [USPTO Trademark Search](https://tmsearch.uspto.gov/). No exact INPI records surfaced for Duvira, Keyvale, or Orlune; no exact or near-wordmark hit surfaced for software goods/services in the U.S. class 9/42 screen. The INPI [Basic Trademark Guide](https://www.gov.br/inpi/pt-br/servicos/marcas/guia-basico) explains that database searches are an initial check and that similar marks still need review.

INPI’s search interface and USPTO records can change after this check; repeat the searches before filing or submission and have counsel assess the proposed mark and goods/services.

## If the product switches to Duvira

No code or product copy was renamed for this check. Before a first store submission, update the brand surfaces together:

1. In [`src/manifest.json`](../../src/manifest.json), set the `name` to **Duvira** and revise the description, action title, and command description to use the brand where appropriate.
2. In [`README.md`](../../README.md), change the working-name heading and branded references; keep “command menu” when it means the interface rather than the product.
3. In [`docs/store-listing.md`](../store-listing.md), update the listing title, short and long description, and any screenshot or store artwork that includes the old name. Use a subtitle such as “Keyboard-first search and browser controls” to make the product easy to understand.
4. Update the release ZIP name in [`scripts/package-extension.mjs`](../../scripts/package-extension.mjs) and the README’s package instructions from `command-menu-<version>.zip` to a Duvira-based filename. [PR #12](https://github.com/pedrotmr/command-menu-chrome-extension/pull/12) introduced the release ZIP packaging flow; it is merged and does not contain a published store listing or external ZIP asset to rename.
5. Remove the “naming remains open” note from [`PRODUCT.md`](../../PRODUCT.md) once the name is approved, and update any store title, short description, screenshots, and promotional assets in the eventual Chrome Web Store listing.
